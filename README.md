# Student Performance Analytics System

## 1. Project Title

Student Performance Analytics System

## 2. Objective

The objective of this project is to analyze student academic performance using Python, NumPy, and Pandas.

The system calculates total marks, average marks, grades, pass/fail results, subject-wise performance, attendance analysis, and identifies top-performing students.

## 3. Technologies Used

- Python
- NumPy
- Pandas
- CSV Dataset
- VS Code

## 4. Dataset Description

The dataset contains 20 student records.

The dataset includes the following fields:

- Student ID
- Name
- Department
- Python Marks
- DBMS Marks
- Data Structures Marks
- Attendance

## 5. Key Features

- Load student data from CSV file
- Display student information
- Calculate total marks
- Calculate average marks
- Assign grades
- Determine Pass/Fail status
- Calculate class average
- Find highest and lowest average
- Find top 5 performing students
- Perform subject-wise analysis
- Identify the best-performing subject
- Analyze attendance
- Display final project summary
